# Rust Practices: Per-Area Rule-to-Check Mapping

**Purpose**: One row per bounded area stating which Rust skill rules govern it and the fastest verification command, so any contributor can start a task without tribal knowledge. Ratified 2026-09-17 (003 sweep, T005); conventions below are what the sweep enforced.

**Precedence**: The constitution (`.specify/memory/constitution.md`) wins over any rule below; conflicts are surfaced in the unit's Verification Record deviation field (FR-010).

**How to use this doc for a new task** (3 steps):
1. Find your area's row; load the listed skills before editing.
2. Apply the conventions; record deviations with reasons.
3. Run the row's fastest verification command; file the Verification Record.
